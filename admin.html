How this dashboard works

This site is static (no server or database), so this dashboard edits content entirely in your browser:

  • Save changes stores your edits in this browser’s local storage. The public site, opened in the same browser, will immediately reflect them — useful for reviewing before you publish.
  • Export content.json downloads your edits as a file. Replace content.json in the website folder (or wherever it’s deployed) with this file to make the changes live for every visitor.
  • The passcode screen prevents casual editing on a shared device; it is not real authentication. For multi-editor or public deployment, wire this dashboard to a real backend (e.g. a small API + database, or a service like Supabase/Firebase) — ask your developer to connect the same “Save” action to that instead of local storage.
